# 📚 ДТК Расписание — Виджет для iPhone

Автоматический виджет расписания занятий для Дзержинского Технического Колледжа (группа 20).

## Как это работает

```
iPhone (Scriptable виджет)
    ↓ загружает JSON
GitHub (raw.githubusercontent.com)
    ↑ обновляет автоматически
GitHub Actions (каждые 4 часа)
    ↓ парсит расписание
Яндекс.Диск / dtk-dz.ru
```

## 🚀 Быстрая установка (15 минут)

### Шаг 1: Создайте GitHub репозиторий

1. Зайдите на [github.com](https://github.com) (создайте аккаунт, если нет)
2. Нажмите **"New repository"** (зелёная кнопка)
3. Назовите репозиторий: `dtk-schedule`
4. Поставьте **Public** (чтобы виджет мог загружать данные)
5. Нажмите **"Create repository"**
6. Загрузите все файлы из этой папки в репозиторий:
   - Можно через веб-интерфейс: **"Add file" → "Upload files"**
   - Или через git:
     ```bash
     cd путь/к/этой/папке
     git init
     git add .
     git commit -m "Initial commit"
     git remote add origin https://github.com/ВАШ_ЮЗЕРНЕЙМ/dtk-schedule.git
     git push -u origin main
     ```

### Шаг 2: Заполните расписание

Отредактируйте файл `data/manual_schedule.json` — впишите своё расписание:

```json
{
  "schedule": {
    "2026-11-11": [
      {"number": 1, "name": "Математика"},
      {"number": 2, "name": "Физика"},
      {"number": 3, "name": "Информатика"}
    ],
    "2026-11-12": [
      {"number": 1, "name": "Русский язык"},
      {"number": 2, "name": "История"},
      {"number": 3, "name": "Химия"},
      {"number": 4, "name": "ОБЖ"}
    ]
  }
}
```

> **Формат даты:** `YYYY-MM-DD` (например, `2026-11-11` = 11 ноября 2026)
>
> **number** — номер пары (1-4). На понедельник не нужно добавлять "Разговоры о важном" — они добавляются автоматически.

После редактирования закоммитьте файл. GitHub Actions автоматически запустится и обновит `data/schedule.json`.

### Шаг 3: Запустите GitHub Actions

1. В репозитории перейдите во вкладку **"Actions"**
2. Если Actions отключены — включите их
3. Выберите workflow **"Update Schedule"**
4. Нажмите **"Run workflow"** → **"Run workflow"**
5. Дождитесь завершения (зелёная галочка)

### Шаг 4: Установите виджет на iPhone

1. Установите приложение **[Scriptable](https://apps.apple.com/app/scriptable/id1405459188)** из App Store (бесплатно)
2. Откройте Scriptable → нажмите **"+"** (создать скрипт)
3. Скопируйте содержимое файла `widget/ДТК_Расписание.js`
4. **ВАЖНО:** в первой строке замените URL:
   ```
   const SCHEDULE_URL = "https://raw.githubusercontent.com/ВАШ_ЮЗЕРНЕЙМ/dtk-schedule/main/data/schedule.json";
   ```
5. Назовите скрипт **"ДТК Расписание"** и сохраните
6. Нажмите ▶ (Play) чтобы проверить — должно показать превью виджета

### Шаг 5: Добавьте виджет на рабочий стол

1. Зажмите пустое место на рабочем столе → **"+"** (добавить виджет)
2. Найдите **"Scriptable"** в списке
3. Выберите размер (**Medium** — рекомендуется)
4. Добавьте виджет
5. Нажмите на виджет → выберите скрипт **"ДТК Расписание"**

### Шаг 6 (опционально): Виджет на экране блокировки

1. Зажмите экран блокировки → **"Настроить"**
2. Выберите зону виджетов (под часами)
3. Найдите **"Scriptable"** → добавьте **прямоугольный** виджет
4. Нажмите на него → выберите **"ДТК Расписание"**

## 📱 Что показывает виджет

| Время | Что на экране |
|-------|---------------|
| До начала пар | Полное расписание на сегодня + таймер до начала |
| Во время пары | Название предмета + обратный отсчёт до конца + следующая пара |
| На перемене | "Перемена" + обратный отсчёт + следующая пара с временем |
| После занятий | Расписание на завтра |
| Выходной | Расписание на ближайший учебный день |

## 🔄 Как обновлять расписание

### Вариант 1: Вручную (простой)
1. Зайдите в репозиторий на GitHub
2. Откройте `data/manual_schedule.json`
3. Нажмите ✏️ (Edit)
4. Добавьте/измените расписание на нужные даты
5. Нажмите **"Commit changes"**
6. GitHub Actions автоматически обновит `schedule.json`

### Вариант 2: Автоматически
GitHub Actions каждые 4 часа пытается скачать расписание с Яндекс.Диска и сайта dtk-dz.ru. Если формат файлов поддерживается (Excel, Word), расписание обновится автоматически.

## 🛠 Решение проблем

**Виджет показывает "Нет данных":**
- Проверьте URL в скрипте Scriptable
- Убедитесь, что `data/schedule.json` содержит расписание
- Проверьте подключение к интернету

**Виджет не обновляется:**
- iOS обновляет виджеты каждые 5-15 минут
- Нажмите на виджет для принудительного обновления

**GitHub Actions не работает:**
- Проверьте вкладку Actions в репозитории
- Убедитесь, что Actions включены (Settings → Actions → General)
